# Operations Hub

HPE IT operations command center.

**Four folders only**

| Folder | Contents |
|---|---|
| `01-app` | `app.py` + HPE logo |
| `02-database` | SQL dump (builds `itops.db` on first run) |
| `03-videos` | RCA video slot |
| `04-feeds` | Salesforce tickets + logs |

## Run

Python 3.10+ only. No pip, no Node.

```bash
python3 01-app/app.py
```

Then open **http://127.0.0.1:8080**

Windows: `py 01-app/app.py`

Download this repo as a zip: GitHub **Code → Download ZIP**.
